DESIGN GOAL

不是一个套壳聊天页，
而是一套可执行的 Agent Runtime。

模型负责决策，Runtime 负责工具执行、权限边界、状态维护、结果回填与收敛控制。Web 层通过独立 Sandbox 驱动 Core，使在线 Demo 与 Agent 核心保持解耦。

CORE CAPABILITIES

围绕 Coding Agent 的关键工程问题展开。

每个模块都服务于同一个目标：让 Agent 在真实工作区里更安全、更稳定地完成多轮任务。

01

Agent Runtime

流式 Agent Loop 驱动“模型决策 → 工具执行 → 结果反馈 → 再次决策”，并维护任务阶段、验证状态与终止条件。

Decide→Act→Observe→Verify
02

Tool System

统一 Registry、JSON Schema、参数校验与调用分发；只读工具可并发，写入与控制流工具保持串行。

03

Permission & Safety

allow / deny / ask 三态决策、HITL 确认、Workspace 边界校验与命令风险分级，把安全约束落在执行层。

04

Context & Memory

大型工具结果外部化、历史压缩、摘要与确定性裁剪，并支持用户级 / 项目级长期记忆召回。

05

MCP

支持 stdio 与 Streamable HTTP MCP Server，将外部工具纳入统一 Schema、权限与执行链路。

06

SubAgent

以 Manager / Agent-as-tool 模式委派独立角色，使用独立上下文和受限工具集并行协作；写入与最终决策仍由主 Agent 收口。

Explorer · code explorationTester · validationReviewer · review

EVALUATION

用固定回归评测，而不是只看 Demo 感觉。

MyCode 使用 Harbor 建立 Coding Agent 回归评测流程，覆盖代码修改、命令执行、调试验证等任务。评测结果用于定位 Agent Loop、验证与终止策略中的行为瓶颈，并持续迭代 Runtime。

Harbor Regression Code Editing Debugging Validation
01Run

固定任务集重复执行，保留 Trial 结果。

02Inspect

按失败类型检查工具轨迹、验证与收敛行为。

03Iterate

针对 Runtime 策略修改后重新回归，比较行为变化。
