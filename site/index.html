ENGINEERING PRACTICE

核心实践

围绕 Coding Agent 的关键机制逐步实现、验证和迭代，重点实践 Runtime、工具系统、上下文管理、多 Agent 协作与扩展机制等工程问题。

01

Agent Runtime

流式 Agent Loop、任务阶段控制、重复调用检测、停滞识别、验证纠偏与循环终止。

02

Tools & Permission

统一 Registry、JSON Schema、参数校验、权限检查和调用调度；高风险操作进入 HITL 人工确认。

03

Context & Memory

按 token 预算管理工具结果与历史消息，支持压缩、外部化以及用户级和项目级长期记忆。

04

SubAgent

将独立的代码探索、测试与审查任务委派给具有独立上下文和受限工具集的专用 Agent。

EXTENSIBILITY

Skills 与 MCP

Skills 提供可复用的方法与知识，MCP 用于连接外部工具，两者都围绕现有 Agent Runtime 工作。

Skills · 可复用技能

按需发现和加载任务技能与参考资料，采用 Progressive Disclosure（渐进式披露）， 启动时只暴露必要信息，需要时再读取正文和资源，避免无关内容持续占用上下文。

MCP · 外部工具扩展

通过 stdio 或 Streamable HTTP 接入外部 MCP Server。MCP Tool 进入 MyCode 后， 继续复用现有 Schema、Permission、Trust 与工具执行链路。

EVALUATION

评测驱动迭代

不只看 Demo 是否成功，而是通过固定回归任务、重复 attempts 和失败轨迹分析判断 Agent 是否真的变好。

Harbor Regression Evaluation

通过失败 Trial、工具调用轨迹和验证结果定位行为瓶颈，再迭代 Runtime、工具调度和完成策略。

实现 → Harbor 回归评测 → 分析失败 Trial / Tool Trajectory → 修改 Runtime → 再评测
