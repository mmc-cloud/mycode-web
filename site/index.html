CORE

核心能力

围绕真实 Agent Runtime 展开，而不是把普通 UI 功能包装成核心能力。

01

Agent Runtime

流式 Agent Loop、任务阶段控制、重复调用检测、停滞识别、验证纠偏与循环终止。

02

Tools & Permission

统一 Registry、JSON Schema、参数校验、权限检查和调用调度；高风险操作进入 HITL 人工确认。

03

Context & Memory

按 token 预算管理工具结果与历史消息，支持压缩、外部化以及用户级和项目级长期记忆。

04

SubAgent

将独立的代码探索、测试与审查任务委派给具有独立上下文和受限工具集的专用 Agent。

EXTENSIBILITY

Skills 与 MCP

Skills 提供可复用的方法与知识，MCP 用于连接外部工具，两者都围绕现有 Agent Runtime 工作。

Skills · 可复用技能

按需发现和加载任务技能与参考资料，采用 Progressive Disclosure（渐进式披露）， 启动时只暴露必要信息，需要时再读取正文和资源，避免无关内容持续占用上下文。
